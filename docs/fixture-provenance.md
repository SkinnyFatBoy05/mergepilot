# Fixture provenance

All fixtures were authored specifically for MergePilot and contain no employer, customer, or production code.

- `entitlement-service`: fictional Northstar access grants; source identity is recorded in the corresponding task `initialFixtureHash` values.
- `webhook-worker`: fictional Bluebird delivery worker; source identity is recorded in the corresponding task manifests.
- `react-access-console`: fictional Acorn administration UI model; source identity is recorded in the corresponding task manifests.

Every person, organization, repository, branch, user, incident, and identifier in the replay is fictional. Hidden oracle identities are SHA-256 values. Oracle source is kept outside the agent runner boundary.
